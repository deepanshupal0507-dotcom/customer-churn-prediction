Customer Churn Prediction

About the Project

Customer churn is an important business problem for companies that want to retain their customers.

In this project, I built a machine learning application to predict whether a telecom customer is likely to leave the company.

The application takes customer details as input and generates a churn prediction along with a churn probability.

Project Features

* Customer data analysis
* Data preprocessing and feature engineering
* Machine learning model training
* Model comparison
* Feature importance analysis
* Interactive Streamlit dashboard
* Customer churn probability prediction
* Customer retention recommendations

Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit
* Joblib

Machine Learning Model

The application currently uses Logistic Regression to predict customer churn.

The model performance is evaluated using appropriate classification metrics.

Application Preview

The dashboard allows users to enter customer information such as:

* Gender
* Internet Service
* Contract Type
* Monthly Charges
* Total Charges
* Payment Method

Based on these details, the application predicts whether the customer is likely to stay or leave.

How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd customer-churn-prediction

3. Install dependencies

pip install -r requirements.txt

4. Run the Streamlit application

streamlit run app.py

Project Objective

The objective of this project is to understand how machine learning can be used to identify customers who may leave a business and help companies take better customer retention decisions.
